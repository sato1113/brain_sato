# MASAKI OS

会議・AI作業・業務データ・リマインド・資料を一つにつなぐ、個人業務基盤（仮称 **MASAKI OS**）。

「会議で決まったこと」「誰に何を依頼したか」「自分が確認しないと進まない事項」「プロジェクト別の進捗」を1画面で把握できる状態を目指す。

## 基本方針（重要）

**アプリを自前構築しない。追加のAPIキー・サーバー・課金なし。**
既に接続済みのコネクタ（tl;dv / Notion / Google Drive）を、**Claude（この環境）から操作**して動かす。議事録の生成・抽出は Claude 自身が行うため、別途 LLM の API キーも不要。

| レイヤー | 採用 | 追加費用 |
|---|---|---|
| 実行・自動化 | Claude（コネクタ操作・議事録生成・抽出） | なし（既存のClaude利用） |
| 会議データ源 | tl;dv コネクタ（既に88件） | なし |
| データ基盤＋ダッシュボード | **Notion**（DBもビューもNotion） | なし |
| ファイル保存（任意） | Google Drive／基本は議事録をNotionページ | なし |
| ソース管理 | GitHub（本リポジトリ） | なし |

新規課金はゼロ。すべて既に保有しているサービスのみで完結する。

## このリポジトリが持つもの

自前アプリのコードは持たない。代わりに **MASAKI OS の設計と運用の“正”** を持つ。

- Notion データベース設計（プロパティ・ビュー）
- 会議取り込み〜議事録生成〜抽出の**手順（パイプライン）**と、それを再現する Claude スキル
- 議事録フォーマット／抽出スキーマ／ASR要確認ルール
- 運用ランブック（どう起動し、何を確認し、どう確定するか）

## 開発フェーズ

- **Phase 1（MVP）**：Notion基盤の構築＋初回縦串（会議→議事録→タスク/決定抽出）＋ホームビュー。半自動で運用。
- **Phase 2**：定期自動実行の検証・導入、週次レポート、AI作業履歴、リマインド。
- **Phase 3**：横断検索・会議前ブリーフィング・自然言語での状況質問。
- **Phase 4**：スライド/資料生成（Canva等）。

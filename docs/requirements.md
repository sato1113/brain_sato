# 要件定義（MASAKI OS）

## 1. 目的と背景

自分（director_of_operations）の業務は、会議・CS・認定パートナー・イベント・システム改修など多岐にわたる。
情報が Zoom/tl;dv、Google Drive、Slack、各種管理システム、AIツールに分散し、「何が決まったか」「誰に何を依頼したか」「自分が確認しないと進まない事項」が一覧できない。

MASAKI OS は、これらを **プロジェクトを軸に集約** し、次を1画面で把握できるようにする。

- 今日やること / 遅れているタスク
- 自動処理の成功・失敗
- 直近の会議と、そこで決まったこと
- 自分がAIで行った作業
- プロジェクト別の進捗
- 自分に確認が必要な事項

## 2. 基本方針（原則）

1. **保存庫とタスク管理を分離する**
   - Google Drive：議事録・録画・資料・成果物（ファイル）
   - Supabase（DB）：タスク・期限・担当・ステータス・数値・関連リンク（構造化データ）
   - ダッシュボード：両者を統合表示
2. **AIに全部を自動実行させない**（自動 / 承認後 / 手動 の3区分。詳細は architecture.md）
3. **プロジェクトを全情報のハブにする**（会議・議事録・決定・タスク・成果物・KPIをプロジェクトに紐付け）
4. **万能AIチャットは最後**。まずデータを正しく残し、紐付け、集計できる状態を先に作る。

## 3. スコープ

### 3.1 Phase 1（MVP）— 本リポジトリの当面のゴール

| # | 機能 | 備考 |
|---|---|---|
| F1 | Googleログイン（自分1アカウントのみ許可） | 自分専用。allowlist 方式 |
| F2 | プロジェクト管理 | 全データの紐付け先 |
| F3 | タスク管理（期限・担当・ステータス・優先度） | 他者への依頼・確認待ちも管理 |
| F4 | **会議の取り込み（tl;dv）** | 初回縦串。slice-01 参照 |
| F5 | **議事録の生成と Drive 保存** | 初回縦串 |
| F6 | **議事録からタスク・決定事項・確認待ちを抽出** | 初回縦串 |
| F7 | リマインド（期限・確認待ち） | 当面は Gmail / Google Calendar |
| F8 | ホームダッシュボード | 今日/今週/期限超過/確認待ち/直近会議 |
| F9 | AI作業履歴の簡易登録 | 要約・成果物URL中心 |
| F10 | 自動処理の成功・失敗ログ | automation_runs |

**初回縦串（最優先）= F4→F5→F6。** これを1本通すことを最初のマイルストーンとする。

### 3.2 Phase 2 以降（スコープ外・将来）

会議完全自動連携、Calendar/Gmail連携の高度化、定常タスク自動生成、週次レポート、認定パートナー/CSのKPIファネル、エラー通知、横断検索・会議前ブリーフィング、スライド/音声/動画生成。

### 3.3 やらないこと（Non-goals, 当面）

- Zoom API の自前実装（tl;dv で代替）
- マルチテナント/複数ユーザー権限（自分専用のため）
- AI会話の全文保存（要約・成果物・履歴のみ）
- スライド/動画の自動生成（Phase 4）

## 4. 対象プロジェクト（初期分類の例）

認定パートナーオンライン化 / Society Pool / CS改善 / HP改修 / セミナー運営 / システム改修（報酬計算等）/ 代理店制度見直し。
※ 実運用で増減する。プロジェクトはユーザーが任意に作成・編集できる。

## 5. 非機能要件

| 区分 | 要件 |
|---|---|
| 利用者 | 単独（自分）。同時アクセスは想定最小 |
| 認証 | Google OAuth。許可メールアドレスの allowlist（`m.sato@holyday.co.jp`）のみログイン可 |
| 機密性 | 会議文字起こし・CS・会員情報は機密。保存対象/期間/閲覧/AI送信可否/削除/操作履歴を定義（architecture.md §6） |
| 監査 | 重要操作（承認・確定・削除・外部送信）は audit_logs に記録 |
| 可用性 | 個人利用のため高可用は不要。定期処理の失敗は検知・通知できること |
| コスト | AI/API利用料を automation_runs 単位で記録し、可視化できる下地を持つ |

## 6. 通知先（初期）

- Gmail（サマリ・確認待ち）
- Google Calendar（期限・会議準備）
- 将来：LINE WORKS / Slack / Discord

## 7. 用語

| 用語 | 意味 |
|---|---|
| 決定事項（decision） | 会議で合意・確定した事項 |
| タスク / action item | 担当・期限つきの実行項目 |
| 確認待ち（confirmation） | 自分または他者の判断・回答待ちで止まっている事項 |
| 縦串（slice） | 1機能をデータ取得〜表示まで縦に通した最小の完成単位 |
